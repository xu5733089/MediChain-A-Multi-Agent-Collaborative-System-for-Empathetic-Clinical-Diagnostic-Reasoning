Agent Design
05 / 10
5-Agent Pipeline

Each agent has a distinct clinical role — Safety Guard intercepts before any LLM call

01
🛡 Safety Guard
Hard-coded keyword rules run before any LLM call. Detects cardiac emergency, stroke, drug crisis, self-harm. Triggers 999 escalation alert. Fast, deterministic, injection-resistant.
SSE: safety_result
02
🗣 Interviewer Agent
Claude Sonnet 4.5 (async). Applies SOCRATES framework. Warm empathetic framing. Accepts multimodal context. Decides when enough symptoms collected — hands off to Diagnostician.
SSE: interviewer_reply
03
🔬 Diagnostician Agent
Chain-of-Thought differential diagnosis. Queries RAG with 3 rewritten variants (Dense + BM25). Returns top-3 diagnoses ranked by confidence with PubMed citation per diagnosis.
SSE: agent_message
04
⚖ Critic Agent
Reviews Diagnostician output for reasoning gaps, hallucinations, drug conflicts, missed red flags. Returns structured verdict with confidence rating. Review integrated back into final diagnosis.
SSE: agent_message
05
📡 Commentary Layer
Claude Haiku 4.5 generates terse professional inter-agent handoff messages — simulating a live clinical secure channel. Streamed to Agent Collaboration panel in real time via SSE.

6 Input Modalities

Patients communicate naturally — text, images, medical scans, documents, audio, and video all understood

🏥
Medical Images
Claude Vision analyses PNG/JPG/BMP for lesions, inflammation, structural abnormalities. Returns annotated findings + clinical significance.
DICOM
🩻
DICOM / X-Ray
pydicom extracts pixel arrays + metadata from CT, MRI, X-ray. Auto window/level normalised before Claude Vision analysis.
🎤
Audio (Speech)
SpeechRecognition transcribes WAV/MP3. Multi-language (en-US, zh-CN, fr-FR). Transcript injected directly into chat context.
📄
PDF Reports
pypdf extracts text from lab results, discharge summaries, clinical reports. Full text passed to Interviewer for context-aware follow-up.
📹
Video Frames
OpenCV samples key frames. Each analysed by Claude Vision. Results merged into unified clinical narrative with temporal context.
💬
Text + OCR
Pillow + Tesseract extracts text from handwritten prescriptions, charts, scanned documents. Mixed-language support.
